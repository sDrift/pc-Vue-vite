OpenLayers 地图初始化

最简单的 OpenLayers 地图创建方法

初始化代码

以下是最基础的 OpenLayers 地图初始化代码：

// 初始化地图 const map = new ol.Map({ target: 'map', // 地图容器的ID layers: [ new ol.layer.Tile({ source: new ol.source.OSM() // 使用OpenStreetMap瓦片 }) ], view: new ol.View({ center: ol.proj.fromLonLat([116.4, 39.9]), // 中心点坐标（北京） zoom: 10 // 缩放级别 }) });

地图控制

核心概念：

  • Map - 地图容器，管理所有图层和控件
  • View - 定义地图显示区域和投影
  • Layer - 地图图层，如瓦片图层
  • Source - 图层的数据源
